### 🇬🇧 English Job Description

#### Role Overview
You will take charge of the official GitHub presence and community ecosystem for Tianji Weather Science & Technology Co., Ltd. The core mission is to drive data growth and developer engagement—scaling project Stars, Forks, downloads, clones, and community interactions.  
This is a cross-disciplinary internship bridging **Meteorology + Open-Source Culture + Technical Advocacy**, tailored for tech geeks passionate about weather modeling, AI, and developer communities.

#### Key Responsibilities
1. **GitHub Account & Metrics Growth**: Maintain official repositories, organize release logs and documentation structures; craft growth strategies to boost Stars, Forks, clones, and community interactions.
2. **Community Governance**: Triage Issues/PRs promptly, answer developer inquiries, establish FAQs, foster an inclusive contributor culture, and inspire co-creation.
3. **Technical Content Development**: Refine READMEs, quick-start guides, use-case notebooks, and tutorials; produce lightweight technical blogs to lower barriers to entry.
4. **Lightweight Technical Adaptations**: Track meteorological open-source trends; assist in debugging code examples, validating notebooks, and supporting version releases.

#### Requirements
- **Engineering Foundations**: Proficient with Git/GitHub workflows; able to read code and run basic debugging. Proficiency in Python is preferred.
- **Meteorological Interest**: Background in Meteorology, Atmospheric Science, Remote Sensing, GIS, Computer Science, or related fields. Passionate about climate datasets and weather models.
- **Open-Source Mindset**: Familiar with open-source community dynamics; proactive in technical writing and community engagement. Prior experience contributing to or managing open-source projects is a big plus.
- **Soft Skills**: Strong self-drive, rigorous analytical mindset, reliable internship commitment, and strong execution capabilities.

#### What We Offer
- **End-to-End Impact**: Gain hands-on experience in building a specialized meteorological AI & computing open-source ecosystem from scratch.
- **Mentorship**: Direct 1-on-1 mentorship from seasoned industry and technical experts.
- **Career Prospects**: High-impact resume credentials with opportunities for return offers (full-time conversion) or official recommendation letters.
